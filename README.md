# Student Admission Form — Java AWT + MySQL

A desktop GUI learning exercise for collecting student admission details and saving records using JDBC.

## Technology

Java AWT, Core Java, JDBC and MySQL.

## Files

- `AdmissionForm.java` — interface and form logic
- `DatabaseConnection.java` — MySQL connection helper
- `IMAGES_ADMISSION_FORM/` — project screenshots

## Local setup

1. Install a JDK and MySQL server.
2. Create the expected `myform` database and `form` table.
3. Set environment variables `DB_URL`, `DB_USER` and `DB_PASSWORD`.
4. Include the MySQL JDBC driver in the project classpath.
5. Compile and launch the admission form.

## Status

Academic desktop prototype. Do not use real applicant records without reviewing validation, access control, data protection and operational security.
